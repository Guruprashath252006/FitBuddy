# FitBuddy - Your Ultimate Fitness Companion 🚀

FitBuddy is a premium, high-performance fitness application designed to help you achieve your goals with style and efficiency. Featuring a state-of-the-art UI with glassmorphism, dynamic gradients, and smooth animations, FitBuddy provides a professional training experience directly in your browser.

## ✨ Key Features

- **🔐 Secure Authentication**: Integrated with Clerk for robust, multi-profile account management.
- **📊 Personalized Onboarding**: Real-time BMI and caloric need calculations tailored to your body.
- **🎯 Goal-Driven Plans**: Custom 8-week workout routines based on your age, weight, and fitness targets.
- **⚡ Premium Workout Player**: Guided exercise-by-exercise flow with set tracking and progress visualization.
- **📚 Smart Exercise Library**: Searchable database with muscle group filters and professional form tips.
- **🌈 Dynamic Design**: Aesthetically pleasing interface with `ColorBends` shaders and HSL gradients.

## 🛠️ Technology Stack

- **Frontend**: React.js with Vite
- **Styling**: Vanilla CSS (Custom Hooks & Modern CSS Properties)
- **Auth**: Clerk (Multi-profile support)
- **Icons**: Lucide React & React Icons
- **Visuals**: Framer Motion & Custom Shader backgrounds

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v16 or higher)
- A Clerk account for API keys

### 2. Installation
```powershell
# Clone the repository
git clone https://github.com/Guruprashath252006/FitBuddy.git

# Enter the directory
cd FitBuddy

# Install dependencies
npm install
```

### 3. Environment Setup
Create a `.env` file in the root directory and add your keys:
```env
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_key_here
```

### 4. Running the App
```powershell
npm run dev
```

## 📱 Page Overview

1. **Dashboard**: Your fitness hub with quick stats (Age, Height, Weight) and streak tracking.
2. **Onboarding**: Step-by-step setup to define your fitness profile.
3. **Workout Player**: An interactive session manager to keep you focused.
